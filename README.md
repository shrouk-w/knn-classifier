# KNN Classifier

A k-nearest-neighbor classifier written in Java. It uses labeled examples to classify new data points, measures accuracy on a test set and allows predictions from the console. Includes Iris flower samples.

## Run

Requires JDK 21. Compile with `javac -encoding UTF-8 -d out src/*.java`, then run `java -cp out Main 3 iris.data iris.test.data`. Sample data comes from the UCI Iris dataset.
